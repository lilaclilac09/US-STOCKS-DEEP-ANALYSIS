## Commands Reference

### Phase 1: Setup
```bash
# Install Payload dependencies
cd payload && npm install

# Copy env template
cp payload/.env.example payload/.env.local

# Edit .env.local to add your PAYLOAD_SECRET
nano payload/.env.local
```

### Phase 2-4: Local Development
```bash
# Terminal 1: Payload backend
cd payload && npm run dev

# Terminal 2: Vite frontend (in another terminal)
npm run dev

# Test migration (after Payload is running)
npm run migrate:data
```

### Phase 5: Automation
```bash
# Generate API key in Payload admin UI, then test:
curl -X POST http://localhost:3001/api/refresh-prices \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"source": "alpha_vantage"}'
```

### Validation
```bash
# Validate data (existing)
npm run validate:data

# Build frontend (existing)
npm run build:prod

# Check Payload API
curl http://localhost:3001/api/companies
curl http://localhost:3001/api/cislunar-companies
```

## Critical Notes

1. **Parallel Mode**: Keep JSON files until Payload is fully tested (1-2 weeks)
2. **API Keys**: Store securely in Railway env vars, never commit to git
3. **CORS**: Configured in `payload.config.ts` to allow localhost:5173 + frontend URL
4. **Database**: Using SQLite for dev; upgrade to PostgreSQL on Railway
5. **Admin UI**: Auto-generated by Payload at `/admin` route
