# Agent Rules

## Primary Goal
Maintain and evolve the finance website safely for `finance.aileena.xyz`.

## Allowed Operations
- Add/update/deactivate company records in `data/companies.json`
- Add/update index records in `data/indexes.json`
- Register/deprecate data sources in `data/sources.json`
- Update operational docs and workflow files
- Update CI workflows for validation and scheduling

## Required Validation
After data or workflow edits, run:
1. `npm run validate:data`
2. `npm run build:prod`

## Prohibited Without Human Approval
- Changing API-key exposure model
- Deleting large sections of existing historical content
- Modifying production domain target

## Preferred Editing Path
Use `scripts/manage-content.mjs` for routine content changes rather than manual JSON edits.
